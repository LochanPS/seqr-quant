Why It Matters

Both primitives protecting this endpoint — the certificate signature (ECDSA-P256) and the session key exchange (X25519) — rest on elliptic-curve mathematics that a cryptographically-relevant quantum computer can break. Traffic captured today can be stored and decrypted later once that capability exists — the harvest-now, decrypt-later risk. The transport protocol itself (TLS 1.3) is current; the exposure is in the algorithms it carries.

Recommended Remediation

1
Deploy a hybrid key exchange — X25519MLKEM768
Closes the harvest-now exposure on the session key immediately, while staying interoperable with classical clients. Supported on OpenSSL 3.5+ / modern TLS stacks.
2
Plan the certificate move to ML-DSA-65
Track CA and PKI support for FIPS 204 signatures; stage a hybrid certificate chain as issuers enable it.
